# Иконки для Input Toolbar

Скопируй сюда SVG-иконки из Figma.

## Нужные файлы

| Файл | Назначение |
|------|------------|
| **attachment.svg** | Кнопка «Прикрепить файл» (скрепка / выбор файла) |
| **send.svg** | Кнопка «Отправить сообщение» (самолётик / стрелка) |

## Как экспортировать из Figma

1. Выдели иконку.
2. В правой панели внизу нажми **Export**.
3. Выбери формат **SVG**, нажми **Export**.
4. Сохрани файл в эту папку с именем `attachment.svg` или `send.svg`.

После добавления файлов их можно будет подключить в компонентах (например, через `react-native-svg`).
